# Digital Twin

AI digital twin that chats about my career, skills and experience.

🔗 **Live demo:** https://twin-8bni.onrender.com
_(The first load may take up to a minute.)_

![Screenshot](screenshot.png)

## What it does

- Answers questions about my background, projects and skills.
- Records the email of visitors who want to get in touch.
- Logs questions it can't answer and notifies me on my phone via Pushover.

## Tech stack

Python · Gradio · Ollama Cloud (OpenAI-compatible API) · Pushover · Render
